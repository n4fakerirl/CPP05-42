# CPP05 - 42 | [FRENCH VERSION] *english below*

## 📚 Description

Le module CPP05 introduit la **gestion des exceptions** en C++ à travers un système administratif composé de bureaucrates et de formulaires.
Il permet de comprendre comment sécuriser un programme en gérant les erreurs d'exécution, tout en approfondissant les notions de classes, d'héritage et de polymorphisme.

---

## 🛠️ Notions abordées

* Exceptions
* `try` / `catch` / `throw`
* Héritage
* Polymorphisme
* Classes abstraites
* Gestion des erreurs
* Classes imbriquées

---

## 📂 Exercices

* **ex00** : Mommy, when I grow up, I want to be a bureaucrat!
* **ex01** : Form up, maggots!
* **ex02** : No, you need form 28B, not 28C...
* **ex03** : At least this beats coffee-making

---

## ⚙️ Compilation

| Commande      | Description                                                            |
| ------------- | ---------------------------------------------------------------------- |
| `make`        | Compile l'exercice et génère un exécutable                             |
| `make clean`  | Supprime les fichiers objets (`.o`)                                    |
| `make fclean` | Supprime les fichiers objets **et** l'exécutable                       |
| `make re`     | Supprime les fichiers objets, l'exécutable, puis recompile entièrement |

# CPP05 - 42 | [ENGLISH VERSION]

## 📚 Description

CPP05 introduces **exception handling** in C++ through an administrative system involving bureaucrats and forms.
